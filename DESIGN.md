# Deshi Tycoon visual direction

The game is an evening table for friends. Use an ink blue background, slate tiles, warm white type, and bright mint actions. Orange, violet, rose, and blue identify property groups and player tokens.

The board is the visual centre. Keep it square and display all forty spaces. The surrounding interface has a narrow player rail and a room or activity panel. A full-width header carries the brand and utility controls. On small screens, let the board occupy the width and place controls below it.

Use a bundled expressive sans font, generous spacing between panels, compact game labels, and tabular numbers for balances. Property strips identify color groups. Cities, airports, and Saint Martin use miniature 3D scenes on ink-blue backgrounds, with larger artwork in property details. Street upgrades add one green-roofed house per level from one to four, then replace the houses with a coral hotel at level five. Keep the landmark visible and use the server's deed level on the board, previews, and property details. Keep names and prices readable over the board artwork. Other spaces use simple icons. Draw dice with CSS perspective and animate a roll as the authored game moment. Animate tokens between spaces. Respect reduced-motion preferences.

The lobby shows actual seats and an actual room code after room creation. Empty seats invite friends. Do not present fictional friends or activity as a live match. The board preview remains visible before a game starts.

During an active game, use the board centre for dice, turn controls, and recent activity. Remove the centre wordmark, flag, slogans, and decorative brand labels. Keep branding in the lobby and app header. Show the newest real events first and reduce the number of visible events on small boards.

Keep game text readable. Right-panel metadata, including turn details, must be at least 12px; activity and chat body text use 14px. Property names use 12px and prices 11px on boards wider than 580px. Smaller boards use fewer activity rows and more compact labels, with readable details available on tap. Use intentional break opportunities for long city names rather than arbitrary character breaks.

The active game replaces the room controls with the current turn, dice, purchase decisions, player balances, property management, and live activity. All visible controls must perform their stated action.
